# 变更：接入 CMS 内容管理能力（第二阶段）

## 背景
第一版静态站上线后，客户还需要自行替换首页主视觉和产品内容，而不依赖开发者反复改代码。相较于自研后台，Headless CMS 更适合当前项目的交付节奏和客户操作能力。

## 变更内容
- 引入 Sanity 作为首页内容与产品内容的管理后台。
- 将本地静态内容切换为 CMS 数据源。
- 支持编辑账号登录、图片上传、内容发布与基础内容更新。
- 为客户准备简单的账号配置与交接说明。

## 影响范围
- 影响规格：`content-management`
- 影响代码：Sanity Schema、前端数据获取层、内容渲染接入、客户交接文档
