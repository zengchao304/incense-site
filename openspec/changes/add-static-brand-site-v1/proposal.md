# 变更：交付第一版静态品牌展示站

## 背景
客户需要在 2026 年 3 月 15 日（周日）前拿到一个可以公开访问的网站链接，用于下周一的简历投递或作品展示。第一版以静态站上线为核心目标，可以在保证视觉质量的同时，把开发与上线风险降到最低。

## 变更内容
- 交付一个响应式单页品牌展示官网，整体风格偏极简、高级感。
- 实现首页核心区块：导航、Hero、产品展示、品牌介绍、页脚。
- 使用本地静态数据与优化后的图片资源，确保开发和上线速度。
- 部署到 Vercel；若自定义域名来不及解析完成，则先使用 Vercel 正式链接交付。

## 影响范围
- 影响规格：`brand-landing-page`、`site-launch`
- 影响代码：前端项目脚手架、样式体系、内容数据层、部署配置
